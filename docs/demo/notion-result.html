怎样把重要的 AI 对话整理到 Notion？

🧪 这是用于项目 README 的虚构演示内容，不包含真实聊天记录。

You Asked

怎样把重要的 AI 对话整理到 Notion，同时保留代码块和数学公式？

ChatGPT Response

可以把每轮问答保存为独立的 Notion 子页面。标题负责搜索，正文保留原对话的层级和格式。

例如，下面的代码块会继续作为代码显示：

const destination = "Notion";
console.log(`Export to ${destination}`);

数学公式也会转换为 Notion equation：

E = mc²

这样导出的内容既能阅读，也方便以后分类、搜索和继续编辑。
